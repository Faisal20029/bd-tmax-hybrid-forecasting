Monthly average of daily maximum temperature (°C), 16 BMD stations, Jan 1972 – Dec 2025, one sheet per station (columns: SL., Station, Year, Month, Temperature). Source: BARC Climate Database Portal (http://barcapps.gov.bd/climate/temp), downloaded 2024 (1972–2023) and September 2026 (2024–2025). No missing values. Station names use the older BARC spellings; see README for the mapping to current BMD names.
